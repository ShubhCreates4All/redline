# 03: Editable red-lines list

**What to build:** A signed-in user can view and edit their own red-lines list — the clause types Redline watches for and how severely — starting from the seven default clause types defined in the brief.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] A new user's red-lines list is pre-populated with the seven default clause types (auto-renewal/hard-to-cancel subscription, unilateral termination/deactivation without cure or appeal, non-compete, indemnification, IP/work-product assignment, liability caps, fee escalators) and their default severity postures
- [ ] The user can edit, add, or remove entries in their red-lines list
- [ ] Edits persist and are scoped to that user only
- [ ] One user cannot see or edit another user's red-lines list
